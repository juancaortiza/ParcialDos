# 🎬 API Cartelera - Examen (Serie I)

Este proyecto implementa un **backend con Node.js y Express** que expone un **controlador API llamado `cartelera`**.  
El API permite **insertar un nuevo registro de película (POST)** en la base de datos SQL Server en Azure.
